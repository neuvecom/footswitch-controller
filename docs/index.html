足元のペダルを、
Mac の好きな操作に。

Footswitch Controller は、USB フットスイッチ PC Sensor FS23（3 ボタン）用の macOS メニューバー常駐アプリです。アクティブなアプリやモードごとに、ペダルへキー操作・テキスト入力・URL・スクリプトなどを割り当てられます。

⬇ 最新版をダウンロード（.dmg） リリースノート

macOS 13 Ventura 以降 / Apple Silicon（M1 以降）· 無料・MIT ライセンス · Developer ID 署名 + Apple 公証済み

主な機能

3 つのペダルそれぞれに、次のアクションを割り当てられます。

キーストローク

⌘ ⌥ ⌃ ⇧ の修飾キーと組み合わせたキー送出。踏んでいる間 50ms 間隔で送る「連射」にも対応。

テキスト入力

任意の文字列をそのままタイプ。\n などの改行・記号も使えます。

URL を開く

Web ページやアプリの URL スキームをワンタップで起動。

Shell / AppleScript

スクリプトを実行して、複雑な処理も足元から。

アプリ別 + モード切替

前面アプリごとに割り当てを変え、1 アプリ内でも複数モードを切り替え可能。

2 台目にも対応

2 台目の FS23 を F18 系で焼き込めば、別の割り当てで同時に使えます。

初期設定：ペダルへのキー焼き込み

アプリは、各ペダルが決まったキーを送る前提で動きます。出荷時の設定とは異なることがあるので、最初にメーカー製ソフト Elfkey で書き込んでください。

ペダル1 台目（Device 1）2 台目（Device 2）※任意
1F13F18
2⌥ Option + F13⌥ Option + F18
3⌃ Control + F13⌃ Control + F18
  1. pcsensor.com/download から Elfkey をダウンロードします（macOS は Apple Silicon / ARM 版）。
  2. フットスイッチを USB 接続し、Elfkey を起動します。
  3. 各ペダルに上の表のキーを割り当て、デバイスへ書き込みます。
コツ：F13 / F18 は Mac のキーボードでは押せません。Elfkey 画面内のソフトウェアキーボードから入力し、Option / Control は修飾キーとして組み合わせて指定してください。

2 台目は、1 台目と同じキーだと OS から区別できないため F18 系を使います。アプリの設定画面では各モードに Device 1 (F13) / Device 2 (F18) のタブが表示されます。

インストール

  1. Releases から FootswitchController.dmg をダウンロードします。
  2. DMG を開き、FootswitchController.app を「アプリケーション」フォルダへドラッグします。
  3. アプリを起動します。署名・公証済みなので、そのまま開けます。
  4. 初回はセットアップ画面が表示されます。「アクセシビリティ設定を開く」から システム設定 → プライバシーとセキュリティ → アクセシビリティ で Footswitch Controller をオンにしてください。
  5. 許可は自動で検知され、すぐに監視が始まります（再起動は不要）。

アップデート

新しいバージョンが出るとメニューバーのメニューに「新しいバージョン … があります」と表示されます。「ダウンロード」から DMG を入手し、アプリケーションフォルダのアプリを置き換えてください。設定はそのまま引き継がれます。

使い方

1. 設定画面を開く

メニューバーのアイコンをクリックし、「設定…」を選びます。

2. プロフィール（アプリ）を選ぶ

左のリストの Default はどのアプリにもマッチする共通設定です。特定のアプリ用の設定を作るには、そのアプリを前面にした状態で 「現在のアプリを追加」 を押します。

3. モードとボタンを設定する

プロフィールごとに複数のモードを作れます（「モード追加」）。各モードで 3 つのボタンにアクションを選び、内容を入力します。アクションに「Switch Mode」を選ぶと、ペダルでモードを切り替えられます。

4. 踏んで確認

設定は自動保存されます。メニューバーのメニューには現在のプロフィール・モードと検知ログが表示されるので、ペダルが正しく反応しているか確認できます。

「ログイン時に起動」はメニューバーのメニューからオン / オフできます。

トラブルシューティング / よくある質問

ペダルを踏んでも何も起きない
  1. メニューバーのメニューで「アクセシビリティ権限: 許可済み」になっているか確認してください。
  2. メニューの「検知ログ」にペダルの入力が出ているか確認します。出ていない場合は、Elfkey でのキー焼き込み（初期設定）を見直してください。
  3. 「デバッグ: 全キーを記録」をオンにすると、ペダルが実際に送っているキーを確認できます。F13 系なら key=105 と表示されます。
  4. ログには出るのに動作しない場合は、前面のアプリに対応するプロフィール・モードの割り当てを確認してください。
許可済みなのに動かない / アップデート後に動かなくなった

macOS の権限情報が古いまま残っていることがあります。システム設定 → プライバシーとセキュリティ → アクセシビリティ で Footswitch Controller を一度「−」で削除し、アプリを再起動して許可し直してください。

それでも直らない場合は、ターミナルで次を実行して権限をリセットし、アプリを起動し直します。

tccutil reset Accessibility com.luckysama.footswitch-controller
Intel Mac で使えますか？

現在配布しているビルドは Apple Silicon（M1 以降）向けです。

キーストロークに F13 を割り当てられない

F13 はペダル自身が送るキーのため、送出するとアプリが自分の入力を再び拾ってしまいます。ループ防止のため、送出キーとしての F13 は使えない仕様です。

Mac App Store では配布しないのですか？

App Store アプリに必須のサンドボックス環境では、キー入力の監視・送出が動作しないため、GitHub Releases での配布としています（Developer ID 署名 + Apple 公証済み）。

他の機種のフットスイッチでも使えますか？

動作確認しているのは PC Sensor FS23 のみです。ただし、上の表のキー（F13 / ⌥F13 / ⌃F13）を送るように設定できる機器であれば、同じように動く可能性があります。

設定はどこに保存されますか？

~/Library/Application Support/com.luckysama.footswitch-controller/settings.json に保存されます。別の Mac への移行時やバックアップにご利用ください。

アンインストール方法
  1. メニューバーのメニューから「終了」します。
  2. 「アプリケーション」フォルダの FootswitchController.app をゴミ箱に入れます。
  3. 設定も消す場合は、上記の設定フォルダを削除し、アクセシビリティ一覧からも削除してください。

プライバシー

Footswitch Controller は、ペダルから送られるキー入力を検知するためにアクセシビリティ権限を使いますが、入力内容を保存・送信することはありません。設定はお使いの Mac 内にのみ保存されます。

通信は、アップデート確認のために GitHub の公開 API（最新リリース情報）へアクセスすることのみです。個人を特定する情報は送信しません。
